# Gym Time · sito

Le pagine pubbliche di assistenza e privacy richieste dall'App Store. Si scrivono qui, nella cartella
`Sito/` del progetto, e si pubblicano sul repository pubblico `gym-time-sito` (GitHub Pages) con:

```bash
git subtree push --prefix Sito sito main
```

dove `sito` è il remoto `git@github.com:cyyz2jt6tv-afk/gym-time-sito.git`. Quel repository contiene
solo queste pagine, mai il codice dell'app.
